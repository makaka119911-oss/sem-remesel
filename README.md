# «Семь ремёсел» — лендинг Татьяны Солнечной

Статическая страница (чистый HTML/CSS/JS, без сборки). Открывается прямо из папки —
`index.html` тянет `style.css`, `script.js` и картинки из `img/` относительными путями.

## Состав

| Файл | Что это |
|---|---|
| `index.html` | вся страница: герой → высказывание → бегущая строка → галерея 7 курсов → что внутри → мастер → стоимость → FAQ → покупка → футер |
| `style.css` | стили (кэш-версия в ссылке: `style.css?v=41`) |
| `script.js` | появление блоков, скролл-режиссура, горизонтальная галерея, параллакс героя |
| `buttons.html` | стенд A/B/C/D для сравнения кнопки-капсулы |
| `img/` | `hero.jpg` (2048×1136, 16:9 десктоп), `hero-mobile.jpg` (1136×2048, 9:16 телефон), `01–07.jpg` (курсы), `master.jpg`, `btn.png` (капсула кнопки, вырезана из присланной картинки), `favicon.svg`, `og.jpg` |
| `preview/` | как герой выглядит сейчас: `hero-16x9-preview.jpg`, `hero-phone-preview.jpg` |
| `DESIGN.md` | паспорт стиля: токены цвета, шкалы размеров/отступов, шрифты, брейкпоинты |
| `PROJECT-NOTES.md` | история проекта и разбор правок героя (05.10) |
| `HERO-PROMPTS.md` | промпты для Leonardo под герой (9:16 и 16:9) |
| `AUDIT-2026-10-05.md` | аудит по ui-design-audit + marketing-cro |
| `prep_assets.py` | подготовка ассетов (вырезание капсулы, ресайзы) — служебный |

## Палитра

Тёмный васильково-синий `#1b2544`, акцент `#5b8def`, мягкий `#a9c6f7`, текст `#f2f6ff`.
Шрифты: Manrope (заголовки) + Inter (текст), подключены с Google Fonts.

## Важное про вёрстку героя

- Затемнение **не живёт внутри `.hero__media`** — там только две картинки (`cover`).
  Слои затемнения — `.hero::before` (шлейф) и `.hero::after` (мягкая виньетка),
  стопы строго монотонные: разворот яркости даёт видимую горизонтальную полосу.
- Строки заголовка — `white-space:nowrap`, размеры через `clamp()`; у кнопки `flex:0 0 auto`,
  иначе флекс сжимает капсулу и она превращается в «полоску».
- Кнопка — псевдоэлемент `::before` с `img/btn.png` (свечение сохранено при вырезании фона).
